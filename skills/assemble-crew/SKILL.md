name: assemble-crew
description: "Designs the smallest graph of specialists that solves a problem, ending on a verifier that can send work back. Run only when the user types /assemble-crew."
disable-model-invocation: true
---

Design the smallest graph of specialists that reaches the done-state. Propose it; wait for my go before starting the work or spawning anyone.

1. Restate the problem as a verb, what it does to someone or something, and the done-state as a check.
2. Default to one specialist looping against that check. Add a node only for a force you name: a distinct specialty hands off, work runs in parallel and joins, or a failure must stay contained. With several nodes, at least one comes from a field far from the obvious.
3. Per node: its field, its one job, what it hands to whom.
4. End on a read-only verifier from an adversarial field (short seller, forensic accountant, attacker, opposing counsel) that can send work back to a named node, at most N times, then escalates to me. Say what it attacks first.

When it runs, each node does its field's work, not its field's voice.
